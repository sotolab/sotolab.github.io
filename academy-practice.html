Overview

이 과정에서 배우는 핵심

4H기초 실습 입문

스마트홈키트를 중심으로 IoT 구조를 이해하고, 실제 연결과 작동 흐름을 손으로 경험하는 데 초점을 둡니다. 교육이 끝난 뒤에도 혼자 다시 따라 해볼 수 있는 기준을 만드는 과정입니다.

추천 대상

IoT를 처음 배우는 분, 제품 구조를 직접 이해하고 싶은 실무자

진행 방식

기초 설명 후 장비 연결, 앱 연동, 제어 흐름 확인 순서로 진행

기대 결과

기본 장치 구성과 제어 구조를 스스로 설명할 수 있는 수준 확보

활용 장면

기초 교육, 사내 입문 교육, 스마트홈 제품 이해용 과정

Curriculum

주요 커리큘럼

STEP4단계 진행
1. 기본 이해

IoT 구조, 연결 방식, 장비 구성과 각 요소의 역할을 이해합니다.

2. 연결 실습

스마트홈키트를 직접 연결하고 기본 설정과 연동 과정을 실습합니다.

3. 제어 흐름

기본 제어와 간단한 자동화 흐름을 확인하며 동작 원리를 익힙니다.

4. 질의응답

실제 적용 시 헷갈리는 부분을 정리하고 다음 학습 방향을 안내합니다.
